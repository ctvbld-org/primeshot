# Task ID: 1
# Title: Setup ComfyUI and comfyui-api in Modal container
# Status: done
# Dependencies: None
# Priority: high
# Description: Set up the Modal container with ComfyUI server and comfyui-api server running on the appropriate ports with proper configuration.
# Details:
1. Install Node 20 in the Modal container
2. Clone the comfyui-api repository from ctvbld/comfyui-api@main
3. Run npm ci --omit=dev to install dependencies
4. Configure ComfyUI to run on localhost:8000
5. Configure comfyui-api to run on localhost:9000
6. Set up environment variables using Modal secrets
7. Create startup script that launches both servers in the correct order

# Test Strategy:
Verify both servers start correctly with no errors. Test a basic request to ensure comfyui-api can successfully forward to ComfyUI. Check logs for proper initialization.
