# Task ID: 5
# Title: Develop Photo Upload System with Quality Checking
# Status: in-progress
# Dependencies: 3
# Priority: high
# Description: Create an intelligent photo upload system with real-time quality checking using OpenCV.js and feedback mechanisms.
# Details:
Implement drag-and-drop and file selection UI for photo uploads. Integrate OpenCV.js for face detection and quality metrics (resolution, lighting, face visibility). Create Sharp.js pipeline for image optimization and processing. Develop real-time feedback system for photo quality issues with specific improvement suggestions. Implement batch upload capability with progress indicators. Store uploaded photos in S3 with references in the Images table.

# Test Strategy:
Test with various photo qualities to verify detection of issues. Validate face detection accuracy across different types of photos. Test upload performance with multiple simultaneous uploads. Verify that quality feedback is accurate and helpful. Ensure processed images maintain sufficient quality for AI processing.

4. Add initial file size validation to prevent extremely large uploads.
5. Develop a thumbnail preview system that shows selected images before upload.
6. Implement a basic progress indicator structure that will be enhanced in later subtasks.
7. Set up the event handlers for file selection and drop events.
8. Create the initial upload queue management system.

Testing approach:

- Test with various file types to ensure only images are accepted.
- Confirm the UI provides appropriate feedback during different upload states.

## 2. Integrate OpenCV.js for Photo Quality Analysis [done]
### Dependencies: 5.1
### Description: Implement the core image quality checking functionality using OpenCV.js, including face detection and quality metrics evaluation.
### Details:
Implementation steps:
1. Set up OpenCV.js library integration in the project.
2. Create a service for image analysis that will run before upload completion.
3. Implement face detection algorithm using OpenCV.js Haar cascades or similar approach.
4. Add quality metric calculations for:
   - Image resolution verification (minimum acceptable dimensions)
   - Brightness and contrast assessment
   - Face visibility and positioning (centered, not too close to edges)
   - Blur detection
5. Develop a quality scoring system that combines multiple metrics.
6. Create specific feedback messages for each type of quality issue.
7. Implement real-time analysis so feedback appears as soon as images are selected.
8. Add visual indicators on thumbnails showing quality status (good/needs improvement).

Testing approach:
- Test with various sample images of different qualities.
- Verify face detection works correctly with different face positions and lighting conditions.
- Confirm quality metrics provide accurate assessments.
- Measure performance to ensure analysis doesn't significantly delay the user experience.
- Test edge cases like images with multiple faces or unusual lighting conditions.
