# Overview
Primeshot is an AI-powered headshot generator that transforms user-provided photos into professional-quality headshots. The platform allows users to create multiple style styles, combining different backgrounds, outfits, and photographic styles to generate a variety of professional headshots. By leveraging advanced AI technology, Primeshot solves the problem of expensive professional photoshoots while providing high-quality, customizable results at a fraction of the cost.

Target Audience:
- Professionals needing LinkedIn/corporate headshots
- Job seekers requiring professional photos
- Real estate agents and business professionals
- Actors and performers needing portfolio shots
- Small business owners and entrepreneurs

Value Proposition:
- Cost-effective alternative to professional photoshoots
- Multiple styles and variations from a single session
- Quick turnaround time
- Convenient online platform
- Professional-quality results

# Core Features

1. Multi-Style Style System
- What: Users can create multiple styles combining background, outfit, and photographic styles
- Why: Provides variety and customization options for different professional contexts
- How: Interface for selecting and combining style elements with live preview

Style Creation Flow:
a. Style Selection
   - Background styles (e.g., office, studio, outdoor, gradient)
   - Outfit styles (e.g., business formal, business casual, creative professional)
   - Outfit colors (predefined palette optimized for professional looks)
   - Photographic styles (e.g., natural light, studio lighting, dramatic, minimalist, B&W)

b. Headshot Generation Logic:
   - 1 style: 20 headshots (Individual Tier Pricing)
   - 2 styles: 30 headshots each (60 total) (Professional Tier Pricing)
   - 3 styles: 20 headshots each (60 total) (Professional Tier Pricing)
   - 4 styles: 30 headshots each (120 total) (Studio Tier Pricing)
   - 5 styles: 24 headshots each (120 total) (Studio Tier Pricing)
   - 6 styles: 20 headshots each (120 total) (Studio Tier Pricing)
   - 7+ styles: 20 headshots each (Studio Tier Pricing + 20 shots add-on)

c. Preview System:
   - Real-time style combination preview using placeholder models
   - Sample gallery for each style combination
   - Style comparison view for multiple styles

2. Intelligent Photo Upload System
- What: Advanced photo quality checking and processing system
- Why: Ensures optimal input quality for AI processing
- How: 
  - OpenCV.js for face detection and quality metrics
  - Sharp.js for image processing and optimization
  - Automated feedback for photo improvement

3. AI Generation Pipeline
- What: Advanced AI model integration for headshot generation
- Why: Creates professional-quality headshots from user photos
- How: Integration with Fal.ai and/or Replicate APIs with fallback mechanisms

4. User Albums
- What: Central hub for managing styles and generated images
- Why: Provides easy access to all user's content and generation progress
- How: Real-time status updates, preview capabilities, and download options

# Technical Architecture

System Components:

1. Frontend:
- Next.js framework
- React components
- TypeScript for type safety
- Shadcn UI components
- Tailwind CSS for styling
- Zod for validation

2. Backend:
- Supabase for authentication and database
- Supabase Edge Functions for AI API integration
- AWS S3 for image storage

3. AI Processing:
- Replicate API integration
- Use 'ostris/flux-dev-lora-trainer' to train User's uploaded pictures
- Use ComfyUI for inference using Flux-dev, trained LoRAs and upscalers
- Deploy our own dedicated instance on Replicate for ComfyUI using 'fofr/any-comfyui-workflow' by either using a private deployment or a fork using Cog as explained in this readme: https://github.com/replicate/cog-comfyui?tab=readme-ov-file
- face-api.js for image quality analysis
- Sharp.js for image processing

Data Models:

1. Users
- Authentication details
- Subscription status
- Creation date

2. Sessions
- Current progress state
- Timestamp
- User reference

3. styles
- Style selections:
  * background_style: string
  * outfit_style: string
  * outfit_color: string
  * photographic_style: string
- Status: enum ('draft', 'pending', 'processing', 'completed')
- Generation progress: number
- Total headshots: number
- Generated headshots: number
- Creation date: timestamp
- Completion date: timestamp
- Preview URL: string
- Sample images: string[]

4. Images
- Source images
- Generated images
- Quality metrics
- S3 references
